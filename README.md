### 🚀 Featured Project & Collaboration

#### 🚦 [NeuroFlow-FL: RL-Based Intelligent Traffic Signal Control](https://github.com/shrinesh-rawool/NeuroFlow-FL)
*Collaborator & Co-Developer*

- **Overview:** Co-designed a simulation-based adaptive traffic control system using Deep Reinforcement Learning (**DQN & PPO**) and **SUMO**, achieving a **73.7% reduction** in average vehicle wait time compared to fixed-time baselines.
- **Privacy-Preserving Architecture:** Built a **Federated Learning** framework enabling multi-intersection coordination without sharing raw local traffic data between nodes.
- **Real-Time Priority & Benchmarking:** Implemented emergency vehicle preemption and conducted a comparative study demonstrating a **~15.7% performance edge** for PPO in complex traffic scenarios.
- **Tech Stack:** `Python` `PyTorch` `Stable-Baselines3` `SUMO` `Federated Learning`
